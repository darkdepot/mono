# Вызов независимого тестировщика

Пять положительных запросов и два соседних отрицательных. Каждый положительный
требует точный Skill `mono:qa` и запрещает чужой `qa`; отрицательные не вызывают
этап. Локальный тест проверяет форму и различение инструментальных вызовов,
не подменяет живой выбор модели.

На хосте после установки оркестратор запускает набор:

```bash
claude plugin eval . --ablation none --runs 3 --threshold 0.8 --no-publish --trust-plugin
```

Живую проверку задания по заданной версии с файлом рецепта проводит оркестратор
на отдельной копии после установки; отчёт, видео и сертификат без права вливания
публикует сессия mono:qa в указанном заданием месте. Воркер этот проход не запускает.
