# projectless

Работай в учебном репозитории, созданном fixture.mjs для этого сценария.
Вход fixture-context.json, задача утверждена; внешние сервисы не вызывай, ответы
Linear только из указанной фикстуры. Итог report.json, хронология действий и запусков
в evidence.jsonl. Начинай mono:implement, затем выполни задачу до отчёта/остановки.

В fixture-context.json действующая одобренная задача mono:issue без проекта, oracle и fingerprint. Выполни её без оркестратора; Linear-ответы даны fixture-адаптером.
