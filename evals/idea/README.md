# Idea: срабатывание этапа

16 запросов на русском: 10 должны вызвать `mono:idea`, 6 не должны. У каждого
ровно один грейдер `tool_used` для `Skill` с `input_match` на `idea`/`mono:idea`;
отрицательные случаи требуют `min: 0`, `max: 0`. Формат по
[документации Claude Code](https://code.claude.com/docs/en/plugin-evals#grader-types).
Запросы не подсказывают имя скилла. Набор проверяет только маршрутизацию.

Оркестратор или воркер Claude Code запускает из корня пакета на итоговом коммите:

```bash
claude plugin eval . --ablation none --runs 3 --threshold 0.8 --no-publish --output-dir <временная папка вне репозитория>
```

`--ablation none` оставляет грейдер вызова в счёте. Все 16 случаев выполняются по
три раза; каждый должен набрать не меньше 0,8. В PR записывается счёт каждого
запроса, версия Claude Code и проверенный коммит. Полные результаты хранятся вне
репозитория; `evals/results/` игнорируется. Read/Glob/Grep/Skill разрешены для
выбора и чтения этапа; настоящих записей Linear в наборе нет.

Разведчики, вопросы по одному, остановка до записи, статус после «Готово» и
поведение в Codex принимаются живой приёмкой после выпуска 0.32.1. Этот набор
такого поведения не доказывает. В Codex проверки Claude не запускаются:
оркестратор возвращает результаты до ship.
