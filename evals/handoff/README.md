# Handoff: срабатывание этапа

Три положительных запроса (нарезать после утверждённого PRD, начать Handoff словами,
правка общего решения после записи пакета) и четыре близких отрицательных (сырая
идея, правка PRD, одна правка на PR без проекта, отклонение перед PR). Тег
`handoff`, грейдер `tool_used` для `Skill` с `input_match` на `handoff`/`mono:handoff`;
у отрицательных `min: 0`, `max: 0`. Только маршрутизация, без записей Linear.
Оркестратор запускает полный набор Idea, Research, Discovery и Handoff на выпуске:

```bash
claude plugin eval . --ablation none --runs 3 --threshold 0.8 --no-publish --trust-plugin
```

Живая приёмка Handoff (запись пакета, старт, запуск из записи) относится к выпуску,
не к этому PR.
