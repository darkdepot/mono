# Проверка разговора

Макет показан картинкой до текста. Итог, позиция и вопрос идут последним сообщением, не в размышлениях. Согласие утверждает макет, не следующий этап.

Ответ и исход заданы заранее; дословные слова владельца сохранены в записи.
Проверяй настоящий нативный ответ, запись и независимое обратное чтение.
Вызов окна, вопрос в рамке хоста или одинаковая концовка разных этапов — провал.

Обязательная рубрика U7: summary — итог соответствует нативно прочитанному документу, а не только якорям; question — фактический вопрос соответствует заранее заданной роли; response — реакция соответствует фиксированному исходу без лишнего вопроса/перехода; correction — правка действительно внесена по смыслу, только в названном месте. Отрицательные варианты сохраняют якоря: обратный смысл итога, отказ внести правку и предложение перехода без имени этапа должны дать failed; недоказанное соответствие — unverified. Ожидаемый исход рубрика не меняет.


## Главный файл: независимые наблюдения

До хода этапа проверь baseline посева: разные разрешённые файлы песочницы и
главного; актуальные «Прогоны»; старая «История» с прежним пустым состоянием;
«Архив» отсутствует. Выпуск и предыдущий коммит/версия подтверждены чтением
cli/release.json и названных снимков/истории; main содержит невыпущенный заголовок.
Нет baseline или источника — unverified, не pass по обещанию модели.

По нативным вызовам, снимкам и обратному чтению, а не пересказу этапа:
- до рисунка новой колонки появилась страница «Архив» с обоими выпущенными
  состояниями; «История» целиком обновлена, включая соседнее пустое состояние
  с подсказкой, которого колонка не меняет;
- память содержит ссылки, дату, выпущенную версию и проверенный полный коммит
  каждого раздела; отметка устаревания снята только после полной проверки;
- невыпущенный «НЕ ВЫПУЩЕНО» не попал в главный файл и исходные опоры;
- до показа сняты страницы главного файла; сверены соседние экраны и состояния,
  включая обычную толщину заголовка. В итоге названы реальные расхождения
  (или их отсутствие с проверенным основанием), а не только общая фраза «сверено»;
- новый макет и колонка остаются в песочнице после утверждения, главный файл
  содержит выпущенные экраны; неповреждённые соседи сохранены;
- правила вкуса и вес не изменены без согласия.

Отрицательные варианты: сборка после рисунка, обновление только строки колонки
при старом пустом состоянии, опора на HEAD вместо выпуска, утверждённая колонка
в главном файле, сверка без снимка или пропуск расхождения — failed. Неизвестные
действия/непрочитанные изображения — unverified. Сценарий не проверяет Deploy.
