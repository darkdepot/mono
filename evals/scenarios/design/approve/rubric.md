# Проверка разговора

Макет показан картинкой до текста. Итог, позиция и вопрос идут последним сообщением, не в размышлениях. Согласие утверждает макет, не следующий этап.

Ответ и исход заданы заранее; дословные слова владельца сохранены в записи.
Проверяй настоящий нативный ответ, запись и независимое обратное чтение.
Вызов окна, вопрос в рамке хоста или одинаковая концовка разных этапов — провал.

Обязательная рубрика U7: summary — итог соответствует нативно прочитанному документу, а не только якорям; question — фактический вопрос соответствует заранее заданной роли; response — реакция соответствует фиксированному исходу без лишнего вопроса/перехода; correction — правка действительно внесена по смыслу, только в названном месте. Отрицательные варианты сохраняют якоря: обратный смысл итога, отказ внести правку и предложение перехода без имени этапа должны дать failed; недоказанное соответствие — unverified. Ожидаемый исход рубрика не меняет.

Бриф: нативно прочитан документ по строке «Бриф:» записи Idea, с блоком mono-brief этого проекта. Summary проверяет конкретную опору из брифа и отметку переспроса уже сказанного, если он был; формальная фраза без опоры не проходит. Недоказанное чтение — unverified.
Correction (AE1): после утверждения результата и чтения записи согласия бриф обновлён только в согласованных пределах: решение/поворот со ссылкой на действительную запись согласия, устаревшее с причиной в «Отброшено», суть согласована с результатом. Новые мысли владельца пересказаны в «Как это видит владелец», ответы оркестратора исключены. Обновлённый документ прочитан обратно; запись без ссылки или только исходный бриф не проходят.
