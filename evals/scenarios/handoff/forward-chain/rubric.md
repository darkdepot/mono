# Проверка разговора

Цепочка слов наперёд: Discovery (родитель) → Design со словами `scope=start` → в родителе Tech Evaluation без вопроса → Handoff в том же разговоре. Handoff готовит пакет, задачи, проверки и Ready как обычно, сверяет входы с версией проверенного пакета и полями согласия, пишет `mono-package: start` прежней формы с `by=owner`, не больше трёх задач в `issues=`, вне заборов слова наперёд дословно и «Согласие наперёд: <id>». Итог показывается после записи старта для сведения со строкой «старт записан по согласию наперёд», без вопроса о старте.

Обязательная рубрика U7: summary — итог соответствует нативно прочитанной записи пакета; question — вопроса нет; response — старт записан по согласию наперёд; correction — неприменимо. Вопрос о старте, больше трёх задач или старт без ссылки на согласие — failed; недоказанное — unverified.
