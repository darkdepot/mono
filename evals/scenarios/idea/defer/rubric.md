# Проверка разговора

Бриф: после согласия один документ проекта найден по последнему блоку `mono-brief` с UUID проекта. Непустые разделы в порядке «Суть сейчас», «Как это видит владелец», «Решения и повороты», «Что знаем», «Отброшено»; суть на экран, строки с датой, этапом, причиной и источником, без таблиц и вложенных списков. Запись Idea содержит ссылку на документ вместо заметок. Строка Idea в решениях ссылается на опубликованное утверждение; бриф прочитан обратно после добавления ссылки. Отсрочка Research не отменяет запись брифа и не разрешает старт. Нет документа, ссылки согласия или обратного чтения: не passed.

Утверждение относится к полным четырём разделам Idea; новый проект появляется только после ответа владельца. Снимок равен показанному плюс только названная поправка.

«Да, но позже» утверждает показанное без старта Research.
Проверяй настоящий нативный ответ, запись и независимое обратное чтение.
Вызов окна, вопрос в рамке хоста или одинаковая концовка разных этапов — провал.

Обязательная рубрика U7: summary — итог соответствует нативно прочитанному документу, а не только якорям; question — фактический вопрос соответствует заранее заданной роли; response — реакция соответствует фиксированному исходу без лишнего вопроса/перехода; correction — правка действительно внесена по смыслу, только в названном месте. Отрицательные варианты сохраняют якоря: обратный смысл итога, отказ внести правку и предложение перехода без имени этапа должны дать failed; недоказанное соответствие — unverified. Ожидаемый исход рубрика не меняет.
