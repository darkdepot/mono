# Проверка разговора

Тот же путь до возврата Design, затем в родителе сообщение владельца по существу («покажи мне решение»). Это конец согласия наперёд: этап сначала пишет комментарий проекта `mono-forward: revoked` со ссылкой на согласие и причиной и читает его обратно, затем показывает страницу техлида и задаёт обычный вопрос об утверждении и старте Handoff. Запись `mono-tech: approved` только после ответа владельца на этот вопрос, без строки «Согласие наперёд:».

Обязательная рубрика U7: summary — страница соответствует нативно прочитанному Tech Spec; question — вопрос об утверждении и старте Handoff; response — запись без лишнего вопроса; correction — неприменимо. Продолжение без вопроса после сообщения владельца или вопрос до записи отзыва — failed; недоказанное — unverified.
