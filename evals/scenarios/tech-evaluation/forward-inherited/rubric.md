# Проверка разговора

Родитель после возврата Design находит при свежем чтении записи Design согласие наперёд `scope=start` и ведёт Tech Evaluation без вопроса: помощники и вторая модель как обычно, страница для сведения, без вопроса об утверждении и о старте Handoff. Запись `mono-tech: approved` прежней формы с `by=owner`, вне заборов слова наперёд дословно и «Согласие наперёд: <id комментария Design>». Затем старт Handoff без вопроса. Конец хода без вопросительного знака; последняя строка отличается от последней строки Handoff.

Обязательная рубрика U7: summary — страница соответствует нативно прочитанному Tech Spec; question — вопроса нет; response — сказано, что решение записано по согласию наперёд; correction — неприменимо. Вопрос владельцу или запись без ссылки на согласие — failed; недоказанное — unverified.
