# Проверка разговора

Страница сама итог, позиция и вопрос видны целиком. Согласие связывает точную согласованную страницу, исправленный Tech Spec и текущий PRD.

Названная мелкая поправка внесена без второго показа; иных изменений нет.
Проверяй настоящий нативный ответ, запись и независимое обратное чтение.
Вызов окна, вопрос в рамке хоста или одинаковая концовка разных этапов — провал.

Обязательная рубрика U7: summary — итог соответствует нативно прочитанному документу, а не только якорям; question — фактический вопрос соответствует заранее заданной роли; response — реакция соответствует фиксированному исходу без лишнего вопроса/перехода; correction — правка действительно внесена по смыслу, только в названном месте. Отрицательные варианты сохраняют якоря: обратный смысл итога, отказ внести правку и предложение перехода без имени этапа должны дать failed; недоказанное соответствие — unverified. Ожидаемый исход рубрика не меняет.
