# Research: срабатывание этапа

Семь запросов на русском с тегом `research`: три положительных (исследуй проект;
что знаем перед решением; «Начать исследование» по утверждённому проекту в Idea), четыре близких отрицательных (сырая идея, правка
готового пакета, вопрос про код, правка PRD). Каждый имеет один грейдер `tool_used`
для `Skill` с `input_match` на `research`/`mono:research`; отрицательные требуют
`min: 0`, `max: 0`. Только маршрутизация, без настоящих записей Linear.

Оркестратор проверяет итоговый коммит одной командой на полном наборе Idea и Research:

```bash
claude plugin eval . --ablation none --runs 3 --threshold 0.8 --no-publish --trust-plugin
```

В PR записываются версия Claude Code, коммит и счёт каждого случая; полные результаты
сохраняются вне репозитория. В Codex эти проверки не запускаются: оркестратор
возвращает результат до ship. Реальное исследование, доступ к поиску и второй модели
проверяет выпуск MONO-178; набор срабатывания этого не доказывает.
