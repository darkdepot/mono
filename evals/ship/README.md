# Вызов Ship

Три положительных запроса и два соседних отрицательных. Каждый положительный
требует точный Skill `mono:ship` и запрещает чужой `ship` (в продуктах он есть у
gstack); отрицательные (вливание и разработка) не вызывают этап. Локальный тест
проверяет форму и различение вызовов, не подменяет живой выбор модели.

На хосте после установки оркестратор запускает набор:

```bash
claude plugin eval . --ablation none --runs 3 --threshold 0.8 --no-publish --trust-plugin
```
