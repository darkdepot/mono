# Artifact Quality Bar

Require zero-context execution without invented behavior or proof.

## Project

Body: what/why/outcome/in/out (`PC-005`). Put lifecycle, active-doc/Issue chips and risk/gate/verdict/evidence/disposition/owner/next record in metadata/resources/comments/handoff (`PC-006`, `PC-007`, `PC-010`), not body. Separate overview/full docs; remove obsolete PRs/raw URLs where chips exist.

## PRD

Apply `references/contracts/prd.md`; retain stable R IDs and A/F/AE when sections exist. Cover actor/capability/benefit and command/path-free proof intent. PRD-lite explicitly lowers confidence. Architecture is allowed only where an agent-workflow product's mechanism explains operator experience.

## Tech Spec

Apply `references/contracts/tech-spec.md`; stable U IDs, PRD trace, system impact/failures/proof/rollout/rollback. API evidence includes deployed enum domains/shapes/edges/date/version or first-in-wave verification spike. Deep/risky requires real seam; no-spec only tiny/low risk; no repair archaeology.

## Issue

Require one PR, Read first / `Прочитать сначала`, AFK/HITL/human dependency, source/blockers/startability, snapshot, surfaces/proof/acceptance/non-goals/links and risk/gate/verdict/evidence/disposition/owner/next. Bug/perf: current/desired/repro/baseline/fix proof. Stable contracts, no brittle edit choreography. Use chips, no attached PRD/Spec or premature PR chips.

## Preflight Certificate

Use complete `mono-preflight certificate`/gates from `skills/mono-preflight/SKILL.md`, worker recovery, model [role:autoreview](model-policy.md#roles); no later-stage claims.

## Ship Green Certificate

Use complete durable `mono-ship green certificate`/`Ship: green` from `skills/mono-ship/SKILL.md` and worker recovery; no delivery/prod claims.

## Deploy Closeout

Record matching green/current head, workflow/merged SHA/target/proof, post-ship check or unavailability, Done outcome/reason, learnings/none and boundary.

## Review Findings

Separate blocking/proposed-fix/decision/fyi; each has evidence, impact, recommendation and owner.
