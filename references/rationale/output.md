# Output rationale

The operator needs product state rather than the internal pipeline. Outcome-first language, confidence boundaries and explicit unknowns make partial work distinguishable from verified delivery. The short risk glossary represents the same scope classes, while the technical tail preserves details for inspection without making them the headline.

Durable machine blocks have a second audience: the next stage recovers certificates by stable English markers and fields. A human lead and an unchanged machine core serve both audiences. Certificate text in a single report field avoids diverging copies.
