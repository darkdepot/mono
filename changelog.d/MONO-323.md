PR теперь открывается черновиком сразу, при первом запросе внешней проверки, а не после неё. Замечания бота, упавшие проверки CI и поручения владельца на PR, которые исполнитель исправил, входят в следующий круг ревью как открытые находки и закрываются, только когда проверяющий подтвердил исправление; замечание с меткой P0 или P1 без исправления не закрывается. Замечания, решённые без правки кода (отказ, наследник, справочное), подтверждает отдельный проход только на чтение. Из черновика PR выходит только при чистой квитанции ревью на текущей версии и без упавших проверок CI; бота упоминают один раз на версию, если он молчит. Позднее замечание, которому нужна правка, возвращает PR в черновик и останавливает Ship с «не сошлось». Где у репозитория нет защиты GitHub от отправки секретов, Ship сам проверяет отправляемые коммиты до каждой отправки. Всё, что Ship публикует на PR, несёт невидимую метку `<!-- mono:ship -->`. Новый скрипт: `scripts/ship-pr.mjs`.
