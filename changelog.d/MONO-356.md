Проект на одну задачу получает короткую запись нарезки и один обязательный круг обоих проверяющих при любом риске. Поправки по формулировке не открывают новый круг; блокирующие находки по сути перепроверяются точечно и отклоняются только опровержением. Встречная проверка PRD, страницы техлида и старта у делегированного проекта на одну задачу принимает только названные поправки по формулировке без нового круга, с привязкой к исправленной версии.
