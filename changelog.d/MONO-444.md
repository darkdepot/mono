Публикация PR больше не проверяет описание (ни форму, ни правдивость отдельной ролью), а сбор больше не повторяет проверку продукта в песочнице. Полную проверку гоняет исполнитель и присылает её итог с запросом сбора; квитанция новой попытки проходит только при его коде 0 на той же версии. Начатые раньше попытки идут по своим закреплённым правилам.
