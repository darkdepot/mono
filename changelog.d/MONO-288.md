### Added
- Драйверы Claude Code и Codex проходят один сценарий с ответами владельца из файла, отдельной персоной для свободных вопросов и сохранением исходного следа. Изоляция и подтверждение monotest проверяются до этапа; ограничение Codex на отказ до выполнения явно отражено.
- Проверяющий следа ловит отсутствующее окно, позицию только размышлением, ошибки карточки и неверный порядок async-итога с точной строкой доказательства. Короткий вход в mono:qa ведёт к справке и рубрике разговора; обязательное чтение доставки не увеличено.
