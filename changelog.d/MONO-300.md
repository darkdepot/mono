Из пака ушли остатки старого ревью через внешний помощник autoreview. Запуск задачи теперь закрепляет маршруты тех, кто реально ревьюит (проверяющий и сверяющий круга ревью), и сбор сверяет их; задачи, запущенные раньше со старым закреплённым маршрутом, проходят сбор как прежде. Таблица усилий старой роли переехала в политику моделей, справочник маршрутов `references/autoreview-routing.md` удалён, правила выбора класса риска теперь в `references/readiness-gates.md`. Поле `prerequisites.autoreviewHelper` в настройке продукта больше не обязательно, старое значение принимается молча. Диспатч больше не создаёт набор данных для ревью по умолчанию: его никто не читал; явный набор по-прежнему закрепляется. Удалены разбор вывода старого помощника в сборе и защита пути к нему.

Важно при установке: выпуск совместимый, окно покоя не нужно. Конфиг самого пака (`prerequisites.autoreviewHelper` и переопределение роли `autoreview` с записями согласия) остаётся до установки, потому что установленная версия ещё требует поле; убрать его можно отдельной задачей после установки. Продукт, где переопределён маршрут исполнителя без согласия пары с ролью ревью, теперь получит отказ при запуске, а не на первом сборе.
