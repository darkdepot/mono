Стенд этапов чинит три сбоя продолжения в той же сессии. Этап, продолженный в разговоре прошлого этапа, теперь может начать следующий этап по списку своего прогона: раньше Tech Evaluation после Discovery видела только Design и не могла начать Handoff. Драйвер сверяет этап со списком текущего прогона при каждом вызове, а схема инструмента знает только общий словарь этапов, одинаковый во всех прогонах. Ответ сценария без разрешения на старт больше не добавляет в список пустое значение. Повтор отклонённой записи документа Linear засчитывается, когда свежее чтение документа содержит все задуманные правки с учётом того, что Linear пишет маркер списка «- » как «* »; добавленные при повторе правки засчитываются только после такого чтения.
