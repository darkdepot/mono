Стенд этапов чинит три сбоя продолжения в той же сессии. Этап, продолженный в разговоре прошлого этапа, теперь может начать следующий этап по списку своего прогона: раньше Tech Evaluation после Discovery видела только Design и не могла начать Handoff. Драйвер получает список текущего прогона только при запуске, из конфига прогона, и этап не может его переписать файлом; каждый вызов сверяется с этим списком, а схема инструмента знает только общий словарь этапов, одинаковый во всех прогонах. Ответ сценария без разрешения на старт больше не добавляет в список пустое значение. Повтор отклонённой записи документа Linear засчитывается, когда повтор делает те же правки, что и отклонённая запись, с той же целью и тем же текстом, с учётом того, что Linear пишет маркер списка «- » как «* », а свежее чтение документа это подтверждает; добавленные при повторе правки засчитываются только после такого чтения. Совпадение текста где-то в документе больше не считается доказательством.
