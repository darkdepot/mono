Путь задаёт изменение: обычная задача проходит один круг ревью, дальше исполнитель правит, гоняет полную проверку и итоговая голова проходит Preflight по его проверке с кодом 0 (`workerVerification`), без нового круга и стоянки. Правка поведения получает живой прогон основного сценария до ревью. `ROUND_LIMIT` остаётся 3, начатые раньше попытки идут по своим закреплённым воротам.
