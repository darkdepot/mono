README стал коротким описанием плагина для людей: что такое Mono, зачем он, весь путь из одиннадцати этапов, из чего состоит, как установить и начать. Прежнее содержимое перенесено без потерь: правила, справочные разделы и 34 правила владельца теперь в `HANDBOOK.md`, заметки «Обновление до…» в `UPGRADING.md`. Убрана только устаревшая строка о текущем выпуске, а слова «README» в перенесённом тексте заменены на «справочник». Проверки плагина, смотревшие на разделы и правила README, смотрят на справочник; флаг быстрой проверки называется `--handbook-only`. Правило изменений обновлено: в той же правке обновляется справочник, а README меняется, только когда меняется то, что Mono такое, как он ставится и как им пользоваться.
