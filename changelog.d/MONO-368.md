Полная проверка пака запускает шаги параллельно и на машинах с 2–7 ядрами: число одновременных шагов считается как половина ядер, не больше четырёх. Раньше на таких машинах, включая проверку в GitHub, шаги шли по одному.

В отчёте цены волны поле `counting` есть у каждой попытки, включая Claude (`per-turn`). Текст правила учёта для волн со смешанными исполнителями описывает оба способа счёта журналов Codex.

Тест ворот перед PR больше не падает случайно на загруженной машине: предел ожидания в нём увеличен с 60 до 600 миллисекунд, чтобы успел пройти хотя бы один опрос.
