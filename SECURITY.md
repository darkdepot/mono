# Security Policy

## Supported Versions

Only the latest release is supported with security fixes.

## Reporting a Vulnerability

Please report vulnerabilities privately through this repository's **Security**
tab by selecting **Report a vulnerability**. Do not open a public issue for a
security vulnerability.

Include the affected version, steps to reproduce the problem, and its potential
impact. Add a minimal example if it helps explain the issue.

We will acknowledge receipt and assess the report, then decide on and address a
fix as capacity allows. We cannot promise response or resolution timelines.
