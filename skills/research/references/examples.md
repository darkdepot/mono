# Примеры сообщений этапа Research

Продукт в примерах условный: сервис записи к мастерам, идея «напоминание клиенту
за день с кнопкой «Перенести»». Это образец тона и формы, а не текст для копирования.
Совет говорит, что делать со следующим шагом, а не какое решение строить.

## Старт

```text
Исследую идею про напоминания клиентам, вернусь примерно через 20 минут.
Вопросов к тебе не будет. Начинаю с того, каким каналом клиенты читают напоминания.
```

## Бриф (в журнал этапа, не владельцу)

```text
Решение: стоит ли делать напоминания клиентам и что для них важно.
Вопросы: 1) каким каналом клиенты читают напоминания; 2) сколько записей теряется
из-за неявок.
Уже знаем: в приложении есть напоминание мастеру за 2 часа (заметки Idea).
Допущения: клиенты переносят, если это легко (самое рискованное, опоры нет: проверяю
как вопрос).
Размер: обычный. Где искать: Linear и код по обоим; опыт людей и конкуренты по первому;
аналитика продукта по второму.
Стоп: ответ по каналу с опорой на данные и опыт людей.
```

## Финал: делать

```text
Готово исследование по напоминаниям: <ссылка>.
Ответ: неявки дают около 9% записей, клиенты чаще читают мессенджер, чем пуш.
Совет: делать. Важно для выбора: пуш клиентам уже пробовали в 2025 и отключили
из-за отписок.
Дальше Discovery: начну с того, какими способами можно снизить неявки.

Техника (можно не читать): разведчик по коду не ответил, факты собрал сам.
```

Пока Discovery нет в паке, в финале «Дальше Handoff: …».

## Финал: не делать

```text
Исследование по напоминаниям: <ссылка>.
Ответ: онлайн-запись уже шлёт напоминание за 2 часа, а неявки после её запуска
не изменились (около 9%).
Совет: не делать в таком виде: само напоминание неявки не снижает.
Дальше Discovery: первым решим, идём ли дальше или ищем другую причину неявок.
```

## Финал: фактов не хватило

```text
Исследование по напоминаниям: <ссылка>. Главный вопрос без ответа: каким каналом
клиенты читают напоминания. Данных о каналах нет, опыт других расходится.
Совет: сначала проверить: неделю слать напоминание в двух каналах части клиентов.
Дальше Discovery: решим, делать ли такую проверку первым шагом.
```

## Не требуется

```text
Исследование не требуется: правка текста одной кнопки, вернуть можно за минуту.
Записал это в документе: <ссылка>. Дальше Discovery.
```

## Если нет доступа к Linear

```text
Этап не начат: в этой сессии нет записи в Linear, а без неё результат исследования
негде сохранить. Ничего не создано.
Чтобы продолжить: открой сессию, где подключён Linear, и скажи «исследуй <проект>».
```

## Идея не одобрена

```text
Исследование не начал: у проекта «Напоминания» нет твоего «да» на идею.
Сначала этап Idea: скажи «идея: <проект>», и начнём с описания.
```
