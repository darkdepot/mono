# Paper: работа в инструменте

Читай только при выбранном `paper`. Общий цикл, смена и проверка картинки —
`drawing.md`, память — `memory.md`, запись и возврат — `approval.md`.

## Вход и опоры

Paper должен быть доступен в текущей сессии и открыт на файле продукта.
Нет доступа — стоп с причиной, предложи Wonder словами, жди выбора владельца.
Сначала прочитай дизайн-систему, оба слоя памяти и экраны «как на проде»,
только затем `get_guide`: без опор он предлагает собственный стиль.

В разделе Paper памяти найди песочницу. Прежний файл со страницами задач
используй как песочницу без уборки; нет файла — создай и запиши служебную ссылку.
Открытые замечания прочитай до нового рисунка: `list_comment_threads`, затем
`get_comment_thread` для полных веток, не только последней реплики.

## Главный файл

Для опоры и сверки экспортируй снимки страницы раздела главного файла.
Раздел выпущен, но страницы нет: по `memory.md` сначала перерисуй экраны и состояния по
снимкам живого продукта с проверенной версией выпуска. Устаревший раздел
обнови целиком. Главный файл отдельно от песочницы, порядок страниц задачи
и отметка «✓» к нему не относятся. Ещё нет выпуска — страницу не создавай,
предложения остаются в песочнице по `memory.md`.

## Страница задачи

Одна страница на задачу, все круги внутри неё, новые версии сверху с подписью
круга, даты и состояния. Имя и иконку по смыслу задачи обновляй вместе. После
утверждения добавь «✓» в имя; на новом круге сними до нового утверждения.
Утверждённые узлы и PNG не меняй: для правок новая версия на той же странице.
Отдельной страницы «Утверждено» нет.

Страница задачи всегда первая. Новая страница появляется после открытой:
перечитай список, одним вызовом задай полный список с задачей наверху и прочитай
порядок обратно. Отказ: перечитай актуальный список и повтори один раз; после
второго отказа честно скажи в итоге, что страница не первая.
Перенос узлов между страницами нужен только для разовой уборки старых страниц.
Он не проверен: проба при первой работе дизайна с подключённым Paper, без
отдельной задачи; новые версии сразу создавай на странице задачи.

## Снимки и показ

`export` выгружает PNG каждого артборда показа. Скопируй возвращённые файлы
в новую временную папку под именами `NN-<название>.png` по порядку показа,
только латиница, цифры и дефисы. Открой каждый файл и проверь по `drawing.md`;
исправил макет — новый экспорт и проверка до показа. Картинка в чате до итога,
одной ссылки недостаточно. Эта же проверенная версия идёт в `approval.md`:
общий `images`, неизменяемая папка `approved/`, `canvas` страницы задачи и
`tool=paper`, обратное чтение, команды `design` и `mono:check design`.

## Замечания

Читай полные ветки, исправь и перепроверь затронутые картинки. По `memory.md`
предложи общее правило владельца, правило продукта или разовую правку.
Новое правило или усиление веса только с согласия владельца. После исправления
и согласованного исхода `set_comment_thread_status` закрывает ветку; прочитай
статус обратно. Позднее замечание после утверждения — новый круг, прежние узлы
и PNG сохраняются.
