# Handoff: что искать в коде

Один разведчик на проект, в фоне, сразу после входа. Claude Code:
`mono:code-scout`. Codex: субагент с `fork_turns: "none"` и текстом агента
`<корень>/agents/code-scout.md` без шапки; модель не принята, повтори без неё.
Модель и усилие из
`node <корень>/scripts/idea-gate.mjs helper --host claude-code|codex --config <конфиг>`.
Передай задание ниже целиком, требования PRD (номера и текст), продукт и путь
к репозиторию. Разведчик недоступен: сделай поиск сам, в заметках записи «без
разведчика».

Задание:

```text
Нужны факты для нарезки работы на задачи, только как есть сейчас, без советов.
«Как у нас» из «Исследования» уже известно, не повторяй его.
- Где живёт каждое требование PRD: места, которые придётся тронуть.
- Какие места общие у разных требований.
- Чем это проверяется сейчас: тесты, команды, ручные проверки.
- Внешние сервисы: есть ли в репозитории живые образцы их ответа и откуда их взять.
До 10 строк на требование, всего до 60 строк. Каждый факт со ссылкой путь:строка.
```

Итог разведчика не пересказывай владельцу. Если он меняет нарезку (общее место,
нет образцов сервиса, нечем проверить), скажи это одной-двумя строками языком
продукта. Пути, которые кладёшь в задачи, сверь точечным поиском и пометь датой
нарезки.
