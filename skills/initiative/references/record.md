# Показ версии и утверждение

## До показа

Готовы цель, выбранная владельцем модель и карта без циклов; все выборы с
отметками, ссылки по `linear-links.md`, описание уже ссылается на «Решение».
Прочитай части обратно и сохрани сырые ответы командой оболочки в `$TMPDIR`:
`initiative.json` (`get_initiative`, `includeProjects`, статус строкой),
`decision.json` (документ с `id`, `content`, `initiativeId` или `initiative.id`).
Комментарии инициативы все страницы: `comments-N.json` и
`comments-N.request.json`, первый `{}`, затем реальный cursor предыдущего
ответа; конец `hasNextPage=false`, без cursor. Не собирай выдуманный ответ.

Для запоминания версии используй экспорт `initiativeFingerprint` из
`<корень>/scripts/idea-gate.mjs` через Node import. Передай ему только
`description` и `content` из обратного чтения, не отправленные черновики.
Запомни `id` инициативы/документа, оба хеша и полный показанный текст до вопроса.
Нормализация уже в T1: убирает строки «Заведён», заменяет теги project/issue
на `id`, приводит ссылки и списки, хвостовые пробелы и пустые строки.
Не делай свой нормализатор; `updatedAt` не версия ни инициативы, ни документа.

Покажи полный согласуемый результат по `owner-dialog.md`: цель, модель и карту,
ссылка на точное «Решение». Позиция и один вопрос текстом об утверждении именно
этой версии и создании проектов в Idea. Утверждение не запускает проекты.
После вопроса никаких вызовов до ответа. Потеряны временные файлы: только
показ и точный ответ из разговора позволяют восстановить их, иначе новый показ.

## После ответа

Не согласие — разговор, записи нет. Любая поправка, включая вместе с «да»,
вносится, снимает отметку изменённого выбора и требует нового выбора/показа;
на прежнее согласие запись не делай. Это исключение из мелкой поправки.

После ясного согласия перечитай описание и решение, заново вычисли оба хеша.
Совпали с показом и те же `id`: запись. Иначе «Было / Стало», новый итог и
вопрос; до нового согласия никаких проектов и записи утверждения.
Один комментарий на инициативе, первая строка внутри забора `text`:

```text
mono-initiative: approved initiative=<uuid> brief-sha256=<хеш описания> decision=<uuid> decision-sha256=<хеш решения> by=owner
```

Вне забора отдельная строка «Владелец: ответил «<его слова дословно>»», без точки
после кавычки. Без строки «Поправка» и `by=orchestrator`. Прочитай комментарий
обратно и обнови дамп всех страниц; последняя запись по `createdAt` действует,
не по `updatedAt`. Более новая кривая запись не разрешает возврат к старой.

## Команда проверки

```bash
node <корень>/scripts/idea-gate.mjs initiative --mode fresh --dump <папка> --config <конфиг>
```

Нужны exit 0, первая строка «Готово» и JSON `code=pass`. `no-record` — нет
утверждения; `stale-brief`/`stale-decision` — новый показ; `bad-record` — проверь
форму, принадлежность частей, страницы и автора, не трактуй как отсутствие.
Проверка связывает именно обратное чтение и последнюю запись, не статус Planned.
Сбой записи: перечитай комментарии, переиспользуй уже записанную ту же версию,
повтори только недостающее один раз. Снова не вышло — назови незавершённое,
остановись без перехода. Только после `pass` переходи к `projects.md`.
