# Исследование и выбор модели

## Готовые материалы и пробелы

Сопоставь готовое исследование, прежнее описание и документы с вопросами,
которые различают варианты модели: что уже известно, что устарело, чего нет.
Не повторяй готовое ради нового документа. Добирай только пробелы, от которых
зависит выбор. Находка со ссылкой и датой отличается от предположения.
Незакрываемый пробел и его цену назови владельцу до выбора модели.

Помощники только существующие `mono:linear-scout`, `mono:code-scout`,
`mono:web-scout`. До запуска модель/усилие выдаёт:

```bash
node <корень>/scripts/idea-gate.mjs helper --host claude-code|codex --config <конфиг>
```

Claude Code: эти агенты с выданной моделью. Codex: встроенный субагент,
`fork_turns: "none"`, модель/усилие из команды, текст соответствующего файла
`<корень>/agents/` без шапки. Читающий доступ, без записей, максимум три
одновременно. Передай продукт, команду, репозиторий, разрешённые источники,
готовые факты и один пробел; ответ: факт, источник с датой, что не проверено.
Не поручай разведчику выбор модели или разговор вместо владельца.
Нужный источник недоступен — назови пробел, не подменяй его выдумкой.

## Варианты модели

Подготовь два-три разных способа достичь цели: кому и как поможет, почему может
сработать, цена и риск, что исключено. Дай свою позицию с причиной и сильнейший
довод против неё. Модель — способ решения проблемы, не выбор технического стека.

До вопроса владельцу один проход другой семьи по вариантам, цели, источникам
и пробелам. Прочитай `<корень>/references/model-policy.md`: Claude Code роль
`second-voice`, Codex `second-voice-alt`. Модель и усилие из этой политики.
Запускай вторую модель из папки продукта. Если `codex exec` запускается из
временной папки вне Git, добавь `--skip-git-repo-check`.
Из Codex: `claude -p --strict-mcp-config --model <модель> --effort <усилие> "<задание>" < /dev/null`;
из Claude Code: `codex exec --ignore-user-config --disable apps -m <модель> -c model_reasoning_effort=<усилие> -s read-only "<задание>" < /dev/null`.
Передний план с таймаутом команды `600000`, только чтение; жди итога,
не прерывай. Тексты вне репозитория вставь в задание, ссылки Linear без
подключений не источник. Попроси сильнейший контрпример, скрытый стратегический
выбор, пропущенный вариант и лишний объём. Прими или отклони замечания с причиной
до показа. Нет ответа/ошибка: повтори один раз; снова нет — стоп «нет второго
мнения», своей моделью не заменяй. Замечания не открывают новые круги ревью.

Покажи варианты, позицию и довод против; последний текст хода — один вопрос,
какую модель выбирает владелец. Не выбирай за него. После ответа сохрани выбор,
причины отказа от других и отметку «Решено владельцем <дата>» в «Решении»,
прочитай обратно. Далее карта, не утверждение всей инициативы вместо выбора.
