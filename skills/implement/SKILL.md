2. Текстовая мелочь: дословно «поведение не меняется», без вставок, с причиной в доказательствах до первой правки и в строке 2 summary.
   Поле `exception` и эта фраза — только для текстовой мелочи.

   worker-contract, команда в доказательстве критерия.

## Остановка

Только: меняющий результат выбор владельца; нет доступа; противоречие пакету/рост
объёма; необратимое; нет прогресса. Три неудачи одной причины — записанный пересмотр
гипотезы; второй без прогресса — `blocked`, сохранить состояние. Повтор до удачи,
отключение теста, рост ожидания не исправление. Технику решай/запиши сам. Стоп всей
задачи: сделанное/один вопрос; продуктовый — владельцу, технический — оркестратору
через отчёт, без оркестратора — владельцу в сессии.

Выходы: `implemented-needs-preflight`, `blocked`, `scope-drift-needs-handoff`,
`needs-human`. В Preflight все `done: true`, без `broken`; иначе `blocked`.
Готовой не объявляй; PR/выкладка дальше.
