не подменяй, пиши «без второго мнения».

## Разведчик

Только если в «Исследовании» нет факта, от которого зависит выбор; один раз.
`mono:code-scout`, `mono:linear-scout` или для внешнего факта `mono:web-scout`
(в Codex: субагент с `fork_turns: "none"` и текстом агента из `<корень>/agents/` без шапки; модель не принята, повтори без неё) с моделью и усилием из
`node <корень>/scripts/idea-gate.mjs helper --host claude-code|codex --config <конфиг>`.
Передай вопрос, продукт, ключ команды Linear, путь к репозиторию.

## Вторая модель

Один проход другой семьи, в фоне, только чтение; модель и усилие роли по
`<корень>/references/model-policy.md`. Из Claude Code роль `second-voice`:
`codex exec -m <модель> -c model_reasoning_effort=<усилие> -s read-only "<задание>" < /dev/null`;
из Codex роль `second-voice-alt`: `claude -p --model <модель> --effort <усилие> "<задание>" < /dev/null`,
нужна сеть. Владельцу: «жду второе мнение пару минут». Передай
что и зачем, предпосылки, находки Research, фразы владельца дословно, решения
и рекомендацию с заданием: сильнейшая версия желания владельца; его самая говорящая
фраза; предпосылка, которая скорее всего неверна; что сделал бы за два дня один
разработчик; меняет ли это рекомендацию. Сведи в 2–4 строки: где согласен, где нет.

## Строитель

Один раз, свежий субагент той же системы на модели сессии, только чтение
(Codex: `fork_turns: "none"`). Задание: ты проектируешь решение по этому PRD (текст
целиком), автора спросить нельзя; назови только вопросы, где пришлось бы гадать
и неверная догадка что-то изменит, с причиной, важные первыми; без оставленного
следующим этапам, решаемого самому и придирок к словам; нет таких: «важного не осталось».
