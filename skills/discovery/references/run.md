# Вход и повторный вход

Команды из папки продукта. `<папка>` = `$TMPDIR/mono-discovery/<короткое имя проекта>/`,
в продукт ничего не клади. `<конфиг>` = `.agents/mono-workflow.config.json`.

## Старый путь

Проект на старом пути (`mono:check discovery`, раздел Old path; при спящей отсечке
это любой проект без утверждённого PRD), а владелец не просил Discovery явно: этап
не начинается и ничего не пишет, дальше `mono:handoff`. Есть `mono-prd: approved`:
вход всегда.

## Задача этапа

Задача проекта с меткой `Этап` и названием на `Discovery:`. Открытая: работай в ней;
закрытая при повторном входе: открой; отложенная, а условие не наступило и владелец
не вернул: скажи, до чего отложено, и стоп. Нет: заведи `Discovery: <проект>`, метка
`Этап` (нет в команде: заведи), исполнитель владелец, тело по
`<корень>/templates/stage-task.md`. Журнал и проверки входа пиши в неё; вход отказан:
причина и куда дальше, задачу закрой.

## Идея

Проект и все страницы его комментариев сохрани ответами Linear как есть
в `<папка>/linear/`: `project.json`; на страницу `comments-N.json` и
`comments-N.request.json` (`{}` для первой, `{"cursor":"<курсор прошлого ответа>"}`
дальше). Ничего в них не правь.

```bash
node <корень>/scripts/idea-gate.mjs check --mode fresh --dump <папка>/linear --config <конфиг>
```

Решает код в строке `idea-gate: <pass|fail>: <код>`, не код выхода; `stale` печатается
как `fail`. `pass`: дальше; `stale`: дальше, в журнал «описание менялось после
утверждения»; `legacy-migrate`: дальше, «Зачем» из описания, в журнал «до записи Idea»;
`no-record`, `bad-record`, `other-project`: в `mono:idea`; другое: стоп, назови код.

## Исследование

Документ по блоку `mono-research` с `uuid` проекта, не по названию. `outcome` это
исход, не совет: `ready`: совет в «Кратко»; `hold`: фактов не хватило; `not-required`:
мелочь. Блок битый (не читается, их в документе больше одного, `outcome` вне набора,
у `hold` или `not-required` нет `reason`): скажи, этап не начинай, дальше `mono:research`.
Блок проекта в нескольких документах: спроси, какой действует, ссылку запиши в журнал,
затем в комментарий решений. Нет документа: `mono:research`, кроме пакета, чьё последнее
одобрение создано строго до `researchGate.since` (нет в конфиге:
`RESEARCH_GATE_DEFAULT_SINCE` в `<корень>/scripts/idea-gate.mjs`; в журнал «до Research»).

## Повторный вход

PRD по `document` из последней записи `mono-prd: approved`, иначе среди документов
проекта; несколько кандидатов: спроси. Находка Handoff или правка владельца до
одобрения пакета: меняй только затронутое, выбор не повторяй, если правка его не
задевает; покажи, что изменилось, и возьми новое утверждение в том же касании.
После перерыва продолжай по комментарию решений и журналу, без пересказа заново.
