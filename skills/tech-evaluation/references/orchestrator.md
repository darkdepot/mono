# Когда этап ведёт оркестратор

Этап выполняет сама сессия оркестратора, не воркер. Все шаги те же, включая
помощника, другую семью, страницу и проверку записи. Одну строку в общий план,
не заменяй план целиком. Владелец в этапе не участвует, окон и технических
вопросов ему нет. Его прежние решения читай как вход, поздняя цитата сильнее
ранней; противоречие нельзя прятать в технику.

Утверди точную страницу сам как владелец: `by=orchestrator`, причина в комментарии
и журнале, включая необратимое, отложенный пункт PRD и строку против прежнего
решения владельца. Не заменяй утверждение фразой «всё нормально». Отложенный пункт
через Discovery в этом же режиме без второй остановки. Перед записью свежий PRD,
смена версии по `run.md`; недоступные обязательные проверки не обходи.

После `mono:check tech` PASS закрой задачу этапа, Handoff начни сам без окна.
Отдельный бриф владельцу по уже утверждённой странице не нужен. Он увидит при
старте работы в итоге Handoff строку «Техлид решил за тебя:»: что необратимо,
что отложено из PRD, что меняет прежнее решение владельца, каждое с причиной.
Нет таких решений: строка говорит «нет». До старта работы всё ещё нужно слово
владельца по правилам Handoff, этап его не заменяет.
