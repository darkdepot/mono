# Как это звучит

Нейтральный продукт записи к мастерам, PRD «Лист ожидания» утверждён. Форма,
не данные другого продукта. Технические детали остаются в Tech Spec.

## План и старт

```text
Читаю решение о листе ожидания и как устроена запись
Выбираю самый простой путь
Проверяю на случаях и приношу страницу
Записываю решение и передаю на задачи
```

```text
Читаю лист ожидания и нынешнюю запись. Принесу одно решение: что строить,
что уже работает и где можем ошибиться.
```

## Находка

```text
В проверке нашёл случай: двое одновременно берут одно окно. Поправил решение:
окно достаётся первому, второй сразу видит, что его уже заняли.
```

## Страница

```text
Лист ожидания: решение техлида
Строим: после отмены окно предлагаем следующему из листа.
Берёт первый; остальные сразу видят, что окно уже занято.
Используем нынешнюю запись, второго списка записей не заводим.
Проверено: обычная отмена, два человека на одно окно, отказ следующего.
Сознательно не строим: отдельный экран замен, всё видно в нынешнем расписании.
Чем рискуем: старое напоминание может уйти отменившему запись; проверяем его отмену.
Необратимо: у одного окна только один записанный человек, закладываем сразу.
```

Под страницей окно «Решение»: «Утверждаем это решение?»
- Утвердить
- Ещё обсудить

## Проверить не на чем

Вместо строки «Проверено»:

```text
Проверить не на чем: отмен с заменой ещё не было, поведение пока не подтверждено.
```

В Tech Spec: первая работа это проба одновременного выбора окна через читаемый
путь продукта; зависимые работы ждут результата. На странице числа PR нет.

## Предложить отложить

Дополнительная строка только о пункте утверждённого PRD:

```text
Предлагаю отложить: выбор любимого мастера, потому что первый свободный уже решает
пустые окна; этот выбор усложнит первый запуск.
```

Владелец нажал «Утвердить»: Discovery переносит этот пункт без новой карточки,
потом этап записывает Tech Spec. Ответ «оставь»: пункт остаётся, решение с ним
пересобирается и страница показывается снова.

## Финал и переход

Отдельное сообщение:

```text
Решение по листу ожидания утверждено: <ссылка на страницу>.
Проверены отмена и два человека на одно окно; оставил одну запись на окно.
Отдельный экран замен не строим. Подробности для работы: <ссылка на Tech Spec>.
```

Затем: «Handoff сверит решение и нарежет задачи». Окно «Начать Handoff» / «Ещё
обсудить». Помощник оркестратора показывает ту же страницу и подписи окна текстом;
ответ с причиной относится к показанной версии, итог возвращается оркестратору.
