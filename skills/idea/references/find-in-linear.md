# Idea: что искать в Linear

Задание для `linear-scout` на этапе Idea. Идею словами владельца, продукт и ключ
команды Linear передаёт агент этапа.

Цель: понять, что про эту идею уже есть, чтобы не завести дубль и опереться
на прошлые решения.

- Первой строкой итога, до «Факты:»: главное для владельца одной фразой, без
  технических слов (есть ли похожий проект и что рядом), только из найденного;
  догадку помечай «похоже». Её покажут сразу.
- Похожие проекты: статус, суть в одну строку, чем отличаются от этой идеи.
- Отменённые похожие проекты: почему отменили.
- Задачи по теме: что уже в работе и что сделано.
- Описание и последние комментарии самых близких проектов: какие решения по теме
  уже приняты.
