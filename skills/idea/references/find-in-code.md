# Idea: что искать в коде

Задание для `code-scout` на этапе Idea. Идею словами владельца и путь к репозиторию
продукта передаёт агент этапа.

Цель: понять, как это работает сейчас, чтобы идея легла на реальный продукт.
Нужна картина, а не аудит.

- Первой строкой итога, до «Факты:»: главное для владельца одной фразой, словами
  интерфейса, только из открытого; догадку помечай «похоже».
- Где в продукте живёт эта тема.
- Как это работает для пользователя сейчас. Если пользователь решает это
  в обход продукта, а в коде видно следы, отметь.
- Что из идеи уже частично сделано: код, флаги, недоделанные экраны.
- Что и почему меняли по этой теме: история только по двум-трём главным местам.
- Пути только к файлам, которые ты открыл, от корня репозитория.
