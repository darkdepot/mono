# Idea: что искать в коде

Задание для `code-scout` на этапе Idea. Агент этапа передаёт его целиком, добавив
идею словами владельца и путь к репозиторию продукта.

Цель: понять, как это работает сейчас, чтобы идея легла на реальный продукт.

- Где в продукте живёт эта тема.
- Как это работает для пользователя сейчас. Если пользователь решает это
  в обход продукта, а в коде видно следы, отметь.
- Что из идеи уже частично сделано: код, флаги, недоделанные экраны.
- Что и почему меняли по этой теме: история изменений и PR.
